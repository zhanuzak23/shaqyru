## 1. Подключить Telegram-бота (обязательно)

Пока не подключён, форма RSVP показывает гостю
«Бот әлі қосылмаған» и ничего не отправляет.

**Шаг 1 — создать бота.** В Telegram написать [@BotFather](https://t.me/BotFather) →
`/newbot` → придумать имя. В ответ придёт токен вида
`8123456789:AAF...`

**Шаг 2 — узнать chat id.** Написать [@userinfobot](https://t.me/userinfobot) →
он ответит вашим `Id` (число).

**Шаг 3 — нажать Start своему боту**, иначе он не сможет вам писать.

**Шаг 4 — вписать в `index.html`**, блок `CONFIG` в начале `<script>`:

```js
var CONFIG = {
  tgToken: "8123456789:AAF...",   // ← токен от BotFather
  tgChat:  "123456789",           // ← ваш id от userinfobot
  startISO: "2026-10-10T18:00:00+05:00"
};
```

Заявки будут падать вам в личку боту:

```
🎉 Той — жаңа жауап

👤 Айгүл Серікқызы
✉️ Жұбайыммен бірге келемін
🕒 29.08.2026, 14:32
```

### ⚠️ Про токен

Токен лежит в коде страницы, а репозиторий публичный — значит **токен видно всем**.
Кто угодно сможет отправлять сообщения от имени этого бота. Для приглашения это
терпимо, но:

- заведите **отдельного** бота только под эту страницу, не используйте рабочий;
- после свадьбы отзовите токен в @BotFather (`/revoke`).

Если нужно надёжно — токен прячется за Cloudflare Worker, страница шлёт запрос
туда, а не напрямую в Telegram.

## 2. Как обновить страницу

Отредактировать `index.html` прямо на github.com (карандаш) → Commit.
Pages пересоберётся за 1–2 минуты, адрес не изменится.

## Заметки

- Страница закрыта от поисковиков через `<meta name="robots" content="noindex">`.
- Шрифты — Google Fonts (Playfair Display + Manrope), обе с казахской кириллицей.
- Музыка грузится (`preload="none"`) только после нажатия «Шақыруды ашу» —
  чтобы не тратить мобильный трафик у тех, кто просто открыл ссылку.
  Звук идёт через Web Audio, потому что на iOS `audio.volume` не работает.
