# Мейіржан & Тоғжан — шақыру

Свадебное приглашение. Статическая страница, без сборки.

**Live:** https://zhanuzak23.github.io/shaqyru/

| файл | что это |
|---|---|
| `index.html` | вся страница: разметка, стили, скрипты |
| `music.mp3` | Дос-Мұқасан — Той жыры |
| `oyu.svg` | ою-өрнек на стартовом экране и в шапке |

## Структура

1. Стартовый экран с монограммой и кнопкой «Шақыруды ашу»
2. Приветствие гостям
3. Арка с именами, датой, временем, адресом и кнопкой 2ГИС
4. Подпись хозяев торжества

## Как обновить

Отредактировать `index.html` прямо на github.com (карандаш) → Commit.
Pages пересоберётся за 1–2 минуты, адрес не изменится.

## Заметки

- Страница закрыта от поисковиков через `<meta name="robots" content="noindex">`.
- Шрифты — Google Fonts (Playfair Display + Manrope), обе с казахской кириллицей.
  Jost и подобные латинские шрифты для казахского текста не годятся — нет глифов
  ә, ң, ғ, қ, ұ, ү, һ, і, ө.
- Музыка грузится (`preload="none"`) только после нажатия «Шақыруды ашу» —
  чтобы не тратить мобильный трафик у тех, кто просто открыл ссылку.
  Звук идёт через Web Audio, потому что на iOS `audio.volume` не работает.
- Поля у `&` в именах намеренно несимметричные (`.names em`): хвост буквы «р»
  в «Мейіржан» съедает просвет сверху, компенсация выравнивает зазоры на глаз.
