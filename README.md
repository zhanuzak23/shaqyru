# Мейіржан & Тоғжан — шақыру

Свадебное приглашение. Один файл, без сборки и зависимостей.

**Live:** https://zhanuzak23.github.io/shaqyru/

---

## Что нужно поправить

Все настройки — в `index.html`, блок `CONFIG` в начале `<script>` (ближе к концу файла):

```js
var CONFIG = {
  phone: "77000000000",              // ← номер WhatsApp для RSVP
  when:  "10 қазан 2026, 18:00",
  place: "«Тамаша» мейрамханасы, Астана, Шарбақты к-сі 40",
  startISO: "2026-10-10T18:00:00+05:00",  // время Астаны (UTC+5)
  hours: 5
};
```

`phone` — в международном формате, без `+` и пробелов. Пока стоит заглушка,
кнопки RSVP ведут в никуда.

## Как обновить страницу

Отредактировать `index.html` прямо на github.com (карандаш) → Commit.
GitHub Pages пересоберёт сайт за 1–2 минуты по тому же адресу.

## Заметки

- Страница закрыта от поисковиков через `<meta name="robots" content="noindex">`.
  Репозиторий публичный, но в Google приглашение не попадёт.
- Шрифты — Google Fonts (Playfair Display + Manrope), обе с поддержкой
  казахской кириллицы. Без интернета текст откатится на системный шрифт.
- Музыка запускается только по нажатию «Шақыруды ашу» — автоплей браузеры блокируют.
